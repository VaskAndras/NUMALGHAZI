# Optimal Racing Line Optimizer

## Problem Statement
In motorsports, finding the fastest way around a race track is a complex challenge known as the optimal racing line problem. This project aims to determine the theoretical minimum lap time and the optimal trajectory for a vehicle navigating a 2D track. Rather than using a real-time driving AI, we approach this as an optimal control and physics simulation problem.

The car's movement is constrained by realistic physical parameters, including speed-dependent friction, aerodynamic drag, and downforce. The core objective is to calculate the vehicle's speed profile along a given path and systematically optimize that trajectory to minimize the overall lap time.

## Project Objectives
To solve this problem and fulfill the course evaluation criteria, the project will implement at least three different numerical methods covered during the semester to achieve the following:
1. **Track and Trajectory Generation:** Create a continuous, smooth representation of the track boundaries and the racing line.
2. **Physics Simulation:** Numerically solve the equations governing the vehicle's dynamics (acceleration, braking, and cornering grip limits).
3. **Trajectory Optimization:** Iteratively adjust the racing line to find the global minimum lap time.
